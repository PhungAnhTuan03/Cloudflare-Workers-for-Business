Báo cáo tổng hợp các hạng mục đã hoàn thành cho trang quản trị, phạm vi chức năng, kiến trúc dữ liệu và tình trạng kiểm thử của dự án.

Trạng thái Đã hoàn thành bản quản trị lõi

1. Tóm tắt điều hành

Website đã được mở rộng từ một website đào tạo/marketing thành một hệ thống có khả năng quản trị vận hành. Trang admin hiện đóng vai trò trung tâm để theo dõi lead tư vấn, khóa học, người dùng, chứng chỉ, chi nhánh, nội dung và nhật ký thao tác.

Hệ thống hiện sử dụng Astro 6 ở chế độ server-rendered, Cloudflare Workers làm runtime, Cloudflare D1 làm database, Cloudflare R2 cho lưu trữ media, Resend cho email và EmDash CMS cho quản trị nội dung. Các luồng nghiệp vụ học viên, giảng viên và admin đã được tách role rõ ràng.

Kết luận: trang admin đã hoàn thành phần quản trị lõi phục vụ vận hành website, nhưng trước production vẫn nên bổ sung kiểm thử e2e, phân quyền chi tiết hơn và dashboard báo cáo nâng cao.

2. Phạm vi đã hoàn thành

Hoàn thành Admin Center

Trang /admin có dashboard tổng quan, sidebar, thống kê, bảng lead, khóa học, người dùng và liên kết CMS.

Hoàn thành Phân quyền role

Hệ thống có các vai trò admin, instructor, student, kèm redirect dashboard theo role.

Hoàn thành Quản lý lead

Lead từ form tư vấn được lưu vào database, có trạng thái xử lý, người phụ trách và lịch sử sự kiện.

Hoàn thành Quản lý khóa học

Admin xem khóa học do giảng viên đăng, theo dõi trạng thái draft/published, học phí, lượt mua và doanh thu.

Hoàn thành Quản lý người dùng

Admin có thể theo dõi danh sách người dùng, role, trạng thái tài khoản và thời điểm tạo tài khoản.

Hoàn thành CMS nội dung

Admin có đường dẫn sang EmDash CMS để quản lý bài viết, trang nội dung và các phần editorial.

3. Chức năng chi tiết của trang Admin

Nhóm chức năng Mô tả File/API liên quan
Tổng quan vận hành Hiển thị tổng người dùng, lead mới, khóa học đang bán, doanh thu, chứng chỉ, chi nhánh active và lớp mở. src/pages/admin.astro, src/lib/admin.ts
Lead tư vấn Quản lý pipeline lead theo trạng thái: mới, đã liên hệ, đang tư vấn, đã hẹn lịch, chốt học, thất bại. /api/admin/leads, /api/business/admin/leads
Người dùng Quản lý tài khoản học viên, giảng viên, admin; hỗ trợ trạng thái active/suspended. /api/admin/users, auth_users
Khóa học marketplace Theo dõi khóa học giảng viên đăng bán, trạng thái đăng bán, doanh thu, lượt mua. /api/admin/courses, instructor_courses
Chứng chỉ Có nền tảng dữ liệu để tra cứu chứng nhận theo mã và trạng thái chứng chỉ. /api/business/certificates/verify, business_certificates
Audit log Lưu dấu các thao tác quản trị quan trọng như cập nhật lead, khóa học, người dùng. business_audit_logs, hàm audit()

4. Kiến trúc hệ thống hiện tại

Frontend/Public website

Astro server-rendered pages cho trang chủ, marketplace, tin tức, liên hệ, profile, dashboard học viên và giảng viên.

Business API

Astro API routes xử lý auth, lead, cart, purchase, upload, marketplace, messages, profile và admin actions.

CMS/Editorial

EmDash CMS quản trị bài viết, trang nội dung, schema, media và giao diện admin riêng tại /_emdash/admin.

Luồng dữ liệu chính

  1. Người dùng truy cập website public và gửi form tư vấn hoặc đăng ký tài khoản.
  2. API lưu dữ liệu vào Cloudflare D1 và ghi nhận các thông tin nghiệp vụ cần thiết.
  3. Admin đăng nhập bằng tài khoản role admin hoặc email được cấu hình trong ADMIN_EMAIL.
  4. Trang admin truy vấn dữ liệu tổng hợp từ các bảng lead, user, course, purchase, certificate, location.
  5. Admin có thể quản lý trạng thái lead, khóa học, người dùng và chuyển sang EmDash CMS để xử lý nội dung.

5. Database và bảng nghiệp vụ

Bảng Vai trò

business_leads, business_lead_events Lưu lead tư vấn và lịch sử chăm sóc lead.
business_locations, business_cohorts Quản lý chi nhánh, lịch khai giảng, lớp học và local SEO.
business_certificates Lưu chứng chỉ và phục vụ tra cứu chứng nhận.
instructor_courses, course_lessons, course_materials Quản lý khóa học do giảng viên đăng bán, bài giảng và tài liệu.
course_purchases, cart_items, coupons Quản lý mua khóa học, giỏ hàng và mã giảm giá.
private_messages Nhắn tin riêng giữa học viên và giảng viên sau khi học viên mua khóa học.

6. API Admin và nghiệp vụ liên quan

Endpoint Mục đích Bảo vệ
GET /api/admin/overview Lấy số liệu dashboard admin. Admin only
PATCH /api/admin/users Cập nhật role hoặc trạng thái người dùng. Admin only
PATCH /api/admin/courses Cập nhật trạng thái khóa học. Admin only
PATCH /api/admin/leads Cập nhật trạng thái lead, người phụ trách, ghi chú chăm sóc. Admin only
POST /api/business/leads Nhận form đăng ký tư vấn từ website public. Public + validate input
GET /api/marketplace/courses Danh sách khóa học marketplace cho học viên. Public

7. Bảo mật và phân quyền

  • Đăng ký public chỉ cho phép role học viên hoặc giảng viên; role admin không mở public.
  • Admin được xác định bằng role admin hoặc email cấu hình trong biến môi trường ADMIN_EMAIL.
  • Mật khẩu được hash bằng PBKDF2 SHA-256 với 100000 iterations, phù hợp giới hạn Web Crypto hiện tại.
  • Session sử dụng cookie sv_auth kết hợp Cloudflare KV binding SESSION.
  • Các API admin gọi hàm kiểm tra quyền trước khi cập nhật dữ liệu.
  • Hệ thống audit log ghi lại thao tác admin quan trọng để hỗ trợ truy vết.

8. Kiểm thử đã thực hiện

Build production Đã chạy npm run build, build Cloudflare server hoàn tất.
Smoke test public route Các route chính như /, /marketplace, /tin-tuc, /lien-he trả HTTP 200.
Protected route /admin, /hoc-vien/dashboard, /giang-vien/dashboard redirect khi chưa đăng nhập.

Local dev port Đã khóa local dev về http://localhost:4322/ và thêm script tự dọn port cũ.

9. Hạn chế còn lại và đề xuất nâng cấp

Cần làm tiếp Phân quyền chi tiết

Tách rõ quyền admin tổng, editor, tư vấn tuyển sinh, kế toán, quản lý đào tạo.

Cần làm tiếp Thanh toán thật

Kết nối cổng thanh toán Việt Nam, trạng thái giao dịch, hóa đơn và đối soát.

Cần làm tiếp Kiểm thử e2e

Bổ sung Playwright cho flow đăng ký, đăng nhập, đăng khóa học, mua khóa học và chat.

Cần làm tiếp Báo cáo nâng cao

Thêm biểu đồ doanh thu, nguồn lead, tỷ lệ chuyển đổi, hiệu quả giảng viên và cohort.

Cần làm tiếp Quản lý media

Chuẩn hóa upload avatar, thumbnail khóa học, tài liệu và chính sách kiểm duyệt file.

Cần làm tiếp Observability

Bổ sung log lỗi, alert, dashboard uptime, tracking Core Web Vitals và API latency.

10. Kết luận

Trang admin đã hoàn thành vai trò quản trị lõi cho website đào tạo công nghệ. Hệ thống hiện có nền tảng đủ tốt để quản lý lead, người dùng, khóa học, giảng viên, học viên, chứng chỉ và nội dung. Với các bước nâng cấp tiếp theo về phân quyền, thanh toán, kiểm thử và báo cáo dữ liệu, dự án có thể tiến gần hơn tới một nền tảng vận hành thực tế cho trung tâm đào tạo.
